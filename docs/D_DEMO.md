# 可视化页面使用说明

页面由林游鑫负责，使用 Streamlit 和 Plotly 实现。指标统一通过 `src/analytics.py` 查询，页面以只读方式连接数仓。

## 启动

在项目目录安装依赖后运行：

```bash
python -m streamlit run app.py
```

默认读取 `data/warehouse/retail.duckdb`，也可以通过环境变量 `RETAIL_DB_PATH` 指定数据库。

## 页面内容

| 页面 | 内容 |
|---|---|
| 销售概览 | 正向交易金额、订单数、记录数量合计、已知客户数、平均订单金额和时间趋势 |
| 商品与业务项目 | 金额 Top 10、记录数量和明细表 |
| 国家与客户 | 国家交易金额排行和已知客户金额 Top 10 |
| 取消与多维分析 | 取消及净额指标、三条金额趋势、CUBE 组合、交叉表和时间 ROLLUP |

各页面提供 CSV 下载。销售概览的“指标口径与数据质量”区域支持下载质量报告。

## 筛选与多维分析

侧边栏选择起止日期和国家，四个页签同步使用该范围。国家留空表示全部国家，日期区间包含两端。

- 选择单个国家进行切片。
- 同时选择日期区间和多个国家进行切块。
- 切换年、月、日粒度进行时间上卷和下钻。
- 按交易金额查看商品、国家和客户排行。

例如选择 2011 年 1 月和法国，再将趋势粒度切换为日，可以查看该市场当月的每日交易情况。

## 指标查询

五项 KPI 由 `analytics.overview()` 返回，趋势及排行分别使用 `trend()`、`products()`、`country_ranking()` 和 `customers()`。订单、客户按筛选范围去重，未知客户不进入客户排行。金额采用英镑 GBP，包含正向商品交易和业务项目，取消记录未冲抵。

页面缓存使用数据库修改时间作为版本。数据库缺失、日期尚未选完整或筛选结果为空时，页面显示对应状态。

## 页面测试

```bash
python -m pytest tests/test_app.py -q
```

测试覆盖缺失数据库、默认页面、法国 2011 年 1 月筛选、无交易日期和不完整日期选择。筛选后的五项指标与直接查询 DWD 的 SQL 结果对照。

多维分析页可组合月份、国家、交易类型，切换汇总层级并下载结果。每次展示一个组合层级，订单与客户数重新去重。净交易记录金额采用销售减取消的事件日期口径。
